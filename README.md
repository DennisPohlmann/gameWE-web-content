# gameWE - web content

gameWE is a statistics system for Source and GoldSrc game servers, in the
style of gameME / HLstatsX. This repository holds **optional content for the
gameWE web frontend ([gameWE-web](https://github.com/DennisPohlmann/gameWE-web))**
that gameWE-web does not ship itself:

- **Templates (skins):** gameWE-web ships only `dark`, `light`, `orange`,
  `modern-dark`, `modern-light` and `modern-orange` (since v0.12.6); every
  other template lives here, among them the ones gameWE-web shipped up to
  v0.12.5.
- **Map pictures:** overview pictures with their calibration for community
  maps that gameWE-web does not ship, used for the kill heatmap on a map's
  page (`/<game>/maps/<id>`).

Every release offers each template and each game's map pictures as its own
`.tar.gz`, ready to unpack into `/var/lib/gamewe/web/templates` or
`/var/lib/gamewe/web/overviews`, each with
its own `<archive>.sha256` file to verify it. This repository was called
`gameWE-web-templates` up to v1.1.1; the old address forwards here.

A template is a folder with `theme.css` (the CSS variables, for the
`modern-*` family also the layout rules), `chart.json` (chart colours) and
`template.json` (display name). There are no images, fonts, scripts or
translation strings in a template.

Current version: see `VERSION` and [CHANGELOG.md](CHANGELOG.md).

## Templates

| Template | Kind | gameWE-web uses instead while it is not installed |
| --- | --- | --- |
| `blue`, `green`, `pink`, `red` | classic colour variants (dark) | `dark` |
| `game-csgo`, `game-css`, `game-cstrike`, `game-dods`, `game-hl2mp` | game designs (dark) | `dark` |
| `game-tf` | game design (light) | `light` |
| `modern-blue`, `modern-gold`, `modern-green`, `modern-pink`, `modern-red` | modern family (layout and colours) | `modern-dark` |

Game designs (`game-*`) are used on the pages of a game's rankings when the
setting "Game designs" is on (Admin > Settings); every template can also be
chosen as the main design.

## Map pictures

| Folder | Game | Maps |
| --- | --- | --- |
| `maps/css` | Counter-Strike: Source (also used by every ranking of a CS:S-based game code) | 409 community maps |

Each map is `<map>.png` (2048 x 2048, no metadata) and `<map>.json`, its
calibration (`pos_x`, `pos_y`, `scale` for a 1024 px picture, like the
`.txt` files of the game's own overviews). The pictures were generated by
gameWE from the map files. None of these maps has the name of a map
gameWE-web ships; if one ever does, the installed picture wins.

## Requirements

- gameWE-web 0.12.6 or newer for the templates (older versions still contain
  them), 0.35.0 or newer for the map pictures
- gameWE-web 0.36.0 and newer read both from fixed folders,
  `/var/lib/gamewe/web/templates` and `/var/lib/gamewe/web/overviews`, in a
  container as well (mount them there). Older versions read them from the
  folders named in `TEMPLATES_DIR` and `OVERVIEWS_DIR`: set those to the same
  two folders.

## Quick start: a template

Install one template, here `blue` from release `1.2.0`:

```bash
VERSION=1.2.0
NAME=blue
BASE=https://github.com/DennisPohlmann/gameWE-web-content/releases/download/v$VERSION

curl -fLO "$BASE/gamewe-web-template-$NAME-$VERSION.tar.gz"
curl -fLO "$BASE/gamewe-web-template-$NAME-$VERSION.tar.gz.sha256"
sha256sum --check "gamewe-web-template-$NAME-$VERSION.tar.gz.sha256"   # must print ": OK"

sudo mkdir -p /var/lib/gamewe/web/templates
sudo tar -xzf "gamewe-web-template-$NAME-$VERSION.tar.gz" -C /var/lib/gamewe/web/templates
```

Each archive contains exactly one folder, `<name>/`, so it lands as
`/var/lib/gamewe/web/templates/blue/`. In Docker mount the folder to the same
path: `-v /var/lib/gamewe/web/templates:/var/lib/gamewe/web/templates:ro`. (gameWE-web
before 0.36.0: also set `TEMPLATES_DIR=/var/lib/gamewe/web/templates` in
`web.env` once and restart it.) Nothing has to be registered: the
site lists every folder it finds under Admin > Settings > Design & logo >
"Design (template)" within a minute. A folder named like one of the removed
templates is used as it is instead of the fallback above.

Updates of gameWE-web do not touch `/var/lib/gamewe/web/templates`. Details, all templates at
once, other platforms and removal: [docs/INSTALLATION.md](docs/INSTALLATION.md).

## Quick start: map pictures

Install the CS:S map pictures from release `1.2.0`:

```bash
VERSION=1.2.0
GAME=css
BASE=https://github.com/DennisPohlmann/gameWE-web-content/releases/download/v$VERSION

curl -fLO "$BASE/gamewe-web-maps-$GAME-$VERSION.tar.gz"
curl -fLO "$BASE/gamewe-web-maps-$GAME-$VERSION.tar.gz.sha256"
sha256sum --check "gamewe-web-maps-$GAME-$VERSION.tar.gz.sha256"   # must print ": OK"

sudo mkdir -p /var/lib/gamewe/web/overviews
sudo tar -xzf "gamewe-web-maps-$GAME-$VERSION.tar.gz" -C /var/lib/gamewe/web/overviews
```

The archive holds the single folder `css/`, so the pictures land in
`/var/lib/gamewe/web/overviews/css/`. In Docker mount the folder to the same
path: `-v /var/lib/gamewe/web/overviews:/var/lib/gamewe/web/overviews:ro`. (gameWE-web
before 0.36.0: also set `OVERVIEWS_DIR=/var/lib/gamewe/web/overviews` in
`web.env` once and restart it.) Details:
[docs/INSTALLATION.md](docs/INSTALLATION.md#map-pictures).

## Verifying the downloads

Every archive in a release has its own `<archive>.sha256` file holding the
one line for that archive. Download it from the same release as the archive
and check:

```bash
sha256sum --check gamewe-web-template-blue-1.0.0.tar.gz.sha256        # Linux
shasum -a 256 --check gamewe-web-template-blue-1.0.0.tar.gz.sha256    # macOS
```

It must show `OK`; anything else (`FAILED`, no such file) means the archive
is damaged or not the released one: do not install it. On Windows compare
`(Get-FileHash .\gamewe-web-template-blue-1.0.0.tar.gz).Hash.ToLower()`
(PowerShell, SHA256 by default) with the first word in
`gamewe-web-template-blue-1.0.0.tar.gz.sha256`.

The archives are built reproducibly by the release workflow from the tagged
commit, so `make package VERSION=<version>` on a checkout of `v<version>`
gives the same checksums (see [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)).

## Building

```bash
make check     # check every template and every map picture
make package   # dist/gamewe-web-template-<name>-<version>.tar.gz,
               # dist/gamewe-web-maps-<game>-<version>.tar.gz, each with its .sha256
make verify    # check every archive in dist/ against its .sha256
```
